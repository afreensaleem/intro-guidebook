## **Lesson 13: Fetch API & Async/Await — Assignment Review Guide**

### **Assignment Rubric**
You can mark the student's assignment as complete if they:
*   [ ] Merged `lesson-12` and submitted `lesson-13` via a new pull request.
*   [ ] **Portfolio Fetch:** Successfully fetched GitHub repositories and displayed them in the "Projects" section.
*   [ ] **JSON Handling:** Used `.json()` (or `JSON.parse`) to process the API response.
*   [ ] **Error Handling:** Included a `.catch()` block or `try...catch` to handle server errors.
*   [ ] **DOM Logic:** Used a `for` loop to create and append `li` elements for each repository.
*   [ ] **Open API Project:** Created a separate repository, performed a test fetch, and linked it in the portfolio `readme.md`.
*   [ ] **Mindset:** Answered the three prompts regarding Problem Solving.

### **What to Look For**
*   **Correct URL:** Check that the student replaced `{GITHUB_USERNAME}` with their actual GitHub username in the fetch URL.
*   **Async Syntax:** If they used `async/await`, ensure the `await` keyword is used for both the `fetch` call and the `.json()` parsing.
*   **DOM Selection:** Verify that they are querying the `projectList` specifically from within the `projectSection` as requested.
*   **Repository Structure:** Check the submission form for a link to the second (Open API) repository and ensure it is not nested inside the portfolio folder.

### **Stretch Goals (Optional)**
*   [ ] Did the student use Flexbox or Grid to style their repository list?
*   [ ] Did the student display more than the minimum 2 data points for their Open API project
